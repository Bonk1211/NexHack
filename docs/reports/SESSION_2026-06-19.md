## 5. Key decisions

- Monorepo: `backend/` (FastAPI, uv), `frontend/` (Next.js 15 App Router, npm).
- **Model family left as env var, not locked** (PRD §25 open decision). WCAG default 2.2 AA.
- Navigation: a11y-tree primary (it is also the trusted signal source); vision LLM is
  stretch fallback. `page.accessibility` is removed in modern Playwright → used
  `locator.aria_snapshot()` instead.
- Two-stream discipline enforced everywhere: trusted WCAG never collapsed into the
  composite (§16) — the credibility defense against the "it's just a costume" critique.

  per working block. `.claude/settings.local.json` sets `GATEGUARD_DISABLED=1` for future
  sessions (gitignored; takes effect on next Claude Code start).
